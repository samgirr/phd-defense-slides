# PhD defense — Samuel Girard

**[Download V3 Final, the animated presentation](https://github.com/samgirr/phd-defense-slides/releases/download/v3.0.0/defense_v3.zip)**

Extract the ZIP and open `defense_v3.html` in a browser. The final deck contains 49 main slides and three Q&A backups. It works offline.

Use Left and Right to change slides, Down for the next animation step, and H to toggle the toolbar. Use the browser’s full-screen mode to present.
